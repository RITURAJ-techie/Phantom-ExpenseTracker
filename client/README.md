# Phantom Expense Tracker — Frontend

The frontend application for **Phantom Expense Tracker**, a full-stack personal finance management platform built to help users track income and expenses, manage budgets, and understand their financial activity.

## 🌐 Live Application

https://phantom-expense-tracker.vercel.app/

---

## 📖 Description

The Phantom frontend provides a clean and responsive interface for managing personal finances.

The main motivation behind the frontend was to create a simple interface that makes financial information easy to understand and interact with. Instead of presenting users with complicated financial tools, Phantom focuses on essential functionality such as transaction management, budgeting, dashboards, and financial reports.

The frontend communicates with the Phantom REST API to authenticate users, manage transactions, create budgets, and retrieve financial information.
